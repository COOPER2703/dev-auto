Contexte :

Je conduit beaucoup en camion et j'aimerais profiter de ce temps pour pouvoir travailler. 
Je suis developpeur et je developpe mes applications via IA

Solution :

Je voudrais un harness pour opencode qui me permettrait d'effectue mon processus de developpement uniquement avec la voix pour pouvoir continuer a regarder la route en toute securite
Le but serait d'avoir un agent vocal avec lequel je pourrais converser pour effectue toutes les taches de mon developpement habituel

Mon processus de developpement est le suivant :
- Idee et session de grilling (/grill-with-docs ou /wayfinder si la tache est plus complexe)
- Resolution des issues wayfinder (si generee)
- Creation de la spec (/to-spec)
- Creation des tickets (/to-tickets)
- Développement automatise, running automatise et parallelise via agent et skill /implement 
- Creation des PR que je review et que je passe sur la main. 

Fonctionnalites :
- En tant qu'utilisateur, je veux pouvoir selectionner le projet / task sur lequel je veux pouvoir travailler
- En tant qu'utilisateur, je veux pouvoir faire une session de grilling vocalement
- En tant qu'application, elle doit pouvoir automatiquement faire les sessions de developpement
- Et plus si idee
